## 2026-07-19 イテレーション1: レアモンスター「黄金ヘキサ」 → ❌棄却

- 変更: 12%/階で弱い金色モンスター出現、倒すとレベルアップ確定(exp=level^3)。ボスと同じmonsters[2]テンプレート復元方式。
- 結果: CLEAR=45%(下限ぎりぎり), nearDeath/100F 10.5→2.6(**-75%**), Lv停滞 18.4→20.3, Lv/100F 60.2→59.9(不変), 無イベント階 7.7→5.6%(改善), max1floor 1666→2108。全文: iter1-golden-2026-07-19.txt
- 判定: 棄却。主目的(Lv停滞解消)に効かず、緊張感が崩壊。死因がターン切れに偏った(4→9件)。
- 学び:
  - **rnd()呼び出しを1回でも追加するとRNG列が全てずれ、同seedでも別のマップ/ロール列になる** — A/B比較の精度が落ちる。以後の新要素は可能な限りrnd()を消費しない設計にする(どうしても必要なら専用RNGを分離する)。
  - 「倒せば得」な受動的報酬はオートプレイ(≒プレイヤーの自然な動線)に拾われにくい。報酬はプレイヤーが既にやる行動(戦闘・移動)に重ねる方が確実に発火する。

## 2026-07-19 イテレーション2: 連鎖キル(コンボ)ボーナス → ❌棄却

- 変更: キル後6ターン以内の連続キルで+15%/連鎖(上限+120%)のボーナス経験値。rnd()不使用の決定的設計。
- 結果: CLEAR=50%, nearDeath/100F 10.5→4.8(**-54%**), Lv停滞 18.4→21.8(**+18%**), Lv/100F 60.2→65.4(+9%), 無イベント階 7.7→5.3%(改善), 蘇生 61.9(不変)。全文: iter2-combo-2026-07-19.txt
- 判定: 棄却。序盤〜中盤の成長は加速した(スモーク325Fまでで停滞8.5階/Lv100超ペース)が、深層は必要経験値がL³で爆発するため線形ブーストでは停滞が解消せず、最大停滞はむしろ悪化。
- 学び(構造的発見): **「プレイヤー強化系」の新要素は2連続で同じ失敗をした** — 序盤だけが楽になり、ベースラインで序盤に集中していたnearDeath(緊張感)が消滅する。緊張感を維持・向上させたいなら、強化ではなく「危険を追加する」方向の要素が必要。

## 2026-07-19 イテレーション3: モンスターハウス＆宝物庫 → ❌棄却 (FUN=-13.2)

- 変更: 20F以降6%でモンスターハウス(全モンスターがプレイヤー半径8以内にスポーン)、8%で宝物庫(ボーナス箱12個)。
- 結果: CLEAR=45%, nearDeath 10.5→5.3, 蘇生 61.2→**73.6**, 無イベント階 4.5%(改善), Lv停滞 23.3, bigHit 1.7。全文: iter3-specialfloors-2026-07-19.txt
- 判定: 棄却。「危険の追加」は緊張感ではなく**即死→蘇生ループ**を生んだ(蘇生+20%)。nearDeath(瀕死で生き延びた瞬間)はむしろ半減。
- 学び: スワーム型の危険はHPが高い状態から一気に0になるためnearDeathを生まない。緊張感を作るのは「**非致死の中ダメージでヒヤリとさせて回復させる**」体験。余っている回復コマンド(死亡時未使用19.7回)に役割を与える方向が有望。

## 2026-07-19 イテレーション4: 隠しトラップ(即時30%ダメージ) → ❌棄却 (FUN=-4.3、過去最善)

- 変更: 毎フロア8個の不可視トラップ。踏むと最大HP30%ダメージ(HP1未満にはならない非致死設計)。
- 結果: CLEAR=55%(維持!), 蘇生 61.2→55.5(改善-9%), nearDeath 10.5→8.6(微減), 成長カテゴリ初のプラス(+3.0), FUN=-4.3。全文: iter4-traps-2026-07-19.txt
- 判定: 棄却だが方向性は正しい。ガードレールを一切傷めずに蘇生依存を減らした初の要素。
- 学び: AIはHP40%未満で即回復するためHPは常時40-100%帯。一撃30%では瀕死帯(≤20%)に届かない。**瞬間ダメージではなく持続ダメージ(毒)なら回復を挟みながら何度も瀕死帯を通過する**はず → iter5へ。

## 2026-07-19 イテレーション5: 毒の罠(15T×2%maxHp, 非致死) → ❌棄却 (FUN=-1.3, ガードレールNG)

## 2026-07-20 イテレーション7: 序盤保護(〜50F: 赤箱除去+敵3割減) → ❌棄却 (FUN=-17.5) — ユーザー発案

- 発端: ユーザー「序盤の理不尽なデスをまず減らしたい。序盤は赤箱が出てこない＋敵がより少ない、を試して」。
- 変更: floorSetの全配置後に 〜50Fで (a)赤箱タイル→床 (b)敵をdespawnで3割減(10→7,15→11,20→14体)。配置後に適用するためフロア生成のrnd()列はベースラインと完全一致(iter1のデシンク対策)。
- 結果(複合=iter7): **序盤デスほぼ消滅**(死亡p25 34→589、50F以前の死=1/20)。しかしFUN=-17.5(緊張感-38, テンポ-42)、CLEAR=45%ぎりぎり、ターン切れ死4→10件。全文: iter7-earlysafe-2026-07-20.txt
- **分解テスト**(単一成分ずつ再計測):
  - 7b 赤箱除去のみ: 序盤デス消滅(p25=627)。FUN=-6.6, CLEAR=35%NG, ターン切れ死11。iter7b-noredbox-2026-07-20.txt
  - 7c 敵3割減のみ: **序盤デス残存(p25=39, hp死5件=ベースライン同数)**。緊張感カテゴリ+12.8だが CLEAR=40%NG。iter7c-fewenemies-2026-07-20.txt
- 判定: 棄却(3変種ともFUN<0またはガードレールNG)。全変更revert済み。
- 学び(分解テストの成果):
  - **序盤理不尽デスの犯人は赤箱**(除去した7/7bで消滅、残した7cで残存) — 敵数は序盤死にほぼ無関係。**→ 訂正(iter8で判明): この結論は誤り。**赤箱除去は1Fから経路トポロジーを変え全軌道をシャッフルするため「早期死が消えた」ように見えただけ(実際は総死亡数がむしろ増加)。AIは赤箱を回避するので赤箱イベント自体は序盤死の原因ではない。
  - **赤箱は「理不尽デス」「緊張感(nearDeath)」「ターン経済」の3役を兼ねる**: hp=1/hp半減の効果が死ぬか瀕死かの分水嶺そのもの(除去するとnearDeath 10.5→4.5に崩壊)。さらに箱破壊は+15ターン収入(battleCheck)なので、序盤の赤箱除去は深層まで効くターン貯金を削り、ターン切れ死を増やした疑い。
  - 〜50Fだけの摂動でも軌道が全部変わるため、CLEAR 35〜45%のどこまでが実力かは20epでは判別不能。**採否を分ける比較は40ep必須**(既知の±10ppノイズがまさに直撃)。
- 次の有望案: 赤箱を「除去」ではなく**序盤だけ非即死化**(例: 〜50FはHp1化→Hp25%化)。箱もターン収入も緊張感も残したまま理不尽だけ削れる筋。判定は40epで。

## 2026-07-20 イテレーション8: 赤箱の序盤非即死化(〜50F: Hp1→maxHp25%) → ✅**採用**(ループ初)

- 変更: boxEffect赤箱ability0を〜50Fのみ `player.hp = max(rint(maxHp*0.25),1)` に緩和(51F〜は従来通りHp1)。rnd()非消費・発火するまで軌道がベースラインと完全一致する設計。
- 計測: **今回から40エピソード判定**(20epのCLEARノイズ±10pp対策)。新ベースライン: baseline40-2026-07-20.txt(CLEAR=50%, hp死7/ターン切れ死13, nearDeath/100F=8.3)。
  - 20ep版ベースラインの「ターン切れ死4件」は下振れノイズだったと判明(40epでは13件) — iter7系の「ターン切れ死倍増」懸念の大半はノイズ。
- 結果: FUN=**+1.2**(理不尽+7.1が主因)、CLEAR=53% OK、即死率0% OK → 採用条件をすべて満たす。全文: iter8-softredbox-2026-07-20.txt
- **エピソード単位の因果分析(決定的)**: 40ep中39epはベースラインと完全同一軌道。差分は ep24 のみで **DEAD@976F → CLEAR** に好転。つまり(1)副作用は文字通りゼロ、(2)発火した唯一のケースで走破を1本救った。
- **iter7の結論を訂正**: AIは赤箱を回避するため、序盤の赤箱Hp1イベントは40運で1回しか発火しない。序盤死7件は両条件で同一(=赤箱と無関係)であり、**真の序盤死原因は通常戦闘**(21〜50F帯でモンスターの毎フロアレベルアップにプレイヤーの成長が追いつかないケース)。7bで序盤死が「消えた」のは軌道シャッフルの錯覚。
- 採用の位置づけ: オートプレイ指標ではほぼ中立(+1.2)だが、**人間プレイヤーは赤箱を頻繁に開ける**ため、「序盤で踏んだ瞬間Hp1→次の一撃で死」という理不尽体験を直接除去する。ハーネスは「人間には効くがAIには無害」を保証した形。
- 残課題(次イテレーション候補): 真の序盤死(21〜50Fの通常戦闘)への対策 — プレイヤーのLv追従を助けるか、序盤帯のみ敵成長率を緩めるか。判定は40epで。

## 2026-07-20 イテレーション9: 遠隔箱破壊(全体攻撃/全消去の箱吸収) → ✅**採用**(9cで確定) — ユーザー発案

- 発端: ユーザー「テンポ改善のため ①全体攻撃の対象に青/緑/紫の箱を含める ②全消去時に青/緑/紫の箱の効果を得る。有利になりすぎるので恩恵は減らして調整」。
- 設計: 遠隔破壊は「直接壊す(フル効果+ターン+15)」の下位互換ボーナス(`remoteBoxBonus`)。青=maxHp/16回復・緑=atk+1%・紫=コマンド1回(蘇生対象外)。全消去は紫箱も消去対象に追加。
- チューニング経過(40ep判定):
  - **9 (初版: 恩恵無制限, 青/8, 緑+2%)**: FUN=+1.6 だが **CLEAR=80%** で大幅超過。Z使用時(囲まれた瞬間)の青回復連鎖でnearDeath 8.3→3.1に崩壊。→ 強すぎ棄却。iter9-remotebox-2026-07-20.txt
  - **9b (吸収3個/回上限 + 青/16 + 緑+1%)**: FUN=+9.1 だが **CLEAR=40%** で下限割れ、ターン切れ死13→17。**構造的発見: Zの箱一掃はメレー農業のターン収入(+15/箱)を消し、ターン経済に穴を開ける**。→ 棄却。iter9b-remotebox-capped-2026-07-20.txt
  - **9c (9b + 遠隔破壊ターン+5/箱・個数無制限)**: **FUN=+9.4(過去最高), CLEAR=60% OK, 即死率0% OK → 採用**。単調さ+31.9(無イベント階4.7%)・テンポ+12.5(max1floor 3707→2647)・蘇生61.1→50.5、ターン切れ死10件(ベースライン13より良い)。iter9c-remotebox-turns-2026-07-20.txt
- 学び: **箱はこのゲームの通貨(効果+ターン)であり、除去系の新要素は必ずターン経済の補償とセットで設計する**。恩恵の調整は「個数上限(構造)」が「係数(連続値)」より効きが読みやすい。CLEAR 80%→40%→60%の3点で挟み撃ちにする二分探索的チューニングが40ep×3回で完了。
