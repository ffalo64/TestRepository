# ダンジョンと不思議の箱 - Python Edition

オリジナルのVisual Basic 6版をPythonでリファクタリングしたバージョンです。

## 概要

ターン制のローグライクRPGゲーム。40x40のダンジョンを探索し、1000階到達を目指します。

## 特徴

- **完全なゲームロジック保存**: VB6版のゲームメカニクスを完全に再現
- **モダンなPython実装**: データクラス、型ヒント、モジュラーアーキテクチャ
- **tkinterベースのGUI**: クロスプラットフォーム対応のシンプルなグラフィック

## 動作環境

- Python 3.10以降
- tkinter（通常Pythonに含まれています）
- Pillow（画像処理ライブラリ）

## インストール

```bash
# リポジトリをクローン（既にクローン済みの場合は不要）
git clone <repository-url>
cd TestRepository/python_version

python --version  # Python 3.10以降であることを確認

# 依存パッケージのインストール

```

## 操作方法

### 基本操作
- **← → ↑ ↓**: 移動
- **Enter**: ゲーム開始（タイトル画面）

### 特殊能力
- **Z**: 全体攻撃 - 全てのモンスターに一律ダメージ
- **X**: HP全快 - プレイヤーのHPを最大まで回復
- **C**: 全消去 - 全ての箱、壁、モンスターを消去
- **D**: モンスター除去 - 全モンスターを箱に変換
- **Enter** (ダンジョン内): 次の階へ強制移動
- **A**: 緑箱を全て開けて次の階へ

## ゲームシステム

### 箱の種類

| 箱の色 | 効果 |
|--------|------|
| 青箱 | HP小回復、モンスターの状態異常解除 |
| 赤箱 | 15種のマイナス効果（ランダム） |
| 黄箱 | 15種の混合効果（ランダム） |
| 緑箱 | 15種のプラス効果（ランダム） |
| 紫箱 | アビリティチャージ増加 |

### モンスターの特殊能力

- **通常**: 特殊能力なし
- **壁破壊**: 壁を破壊できる
- **スロー**: 移動速度が遅い
- **箱攻撃**: 箱を破壊できる
- **ステルス**: 透明（プレイヤーを追跡しない）

### ステータス

- **HP**: 体力（0になるとゲームオーバー）
- **レベル**: 経験値が溜まるとレベルアップ
- **攻撃力**: 高いほど与えるダメージが大きい
- **守備力**: 高いほど受けるダメージが小さい
- **ターン**: 行動ごとに減少（0でゲームオーバー）

### 戦闘システム

ダメージ計算式:
```
ダメージ = 攻撃力 × (0.9~1.1のランダム) ÷ 守備力
```

レベルアップ条件:
```
経験値 >= レベル^3
```

## 技術詳細

### アーキテクチャ

- **モジュラー設計**: 各機能を独立したモジュールに分離
- **データ駆動**: `dataclass`を使用した型安全なデータ構造
- **オブジェクト指向**: クラスベースの設計パターン

### VB6からの主な変更点

1. **構造化されたモジュール**: VB6の`.bas`ファイルを機能別にPythonモジュールに分割
2. **型安全性**: Python 3.10+の型ヒントを活用
3. **列挙型の使用**: `IntEnum`でゲームモード、タイルタイプなどを定義
4. **簡潔な文法**: VB6の冗長な構文をPythonicなコードに変換
5. **モダンなGUI**: tkinterを使用したクロスプラットフォーム対応
